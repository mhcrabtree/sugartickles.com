Two Players, One Console

Playing as a couple, with a path each

The simplest plan for two players is two separate saves, one path each, on the same console. You each pick a path and stay with it, and compare notes. Any pairing works, including two of the same path, and every companion can be romanced no matter who your character is.

Couch co-op is a bonus we want to test. We don't yet know how romances and party choices work when two people share one story.

To verify while provingCheck how romances and companion choices work in split-screen co-op on the Xbox Series X, and whether each player can follow a different path in the same save.

How a Path Works

What each page gives you

  1. Build the character as written: race, background, ability scores, skills. You choose how they look.
  2. Follow the level-by-level table to pick abilities and spells as you level.
  3. Tick off the in-character choices act by act. If you miss one, the page says how to repair it.
  4. Check the Never Do This table before any big decision.
Save oftenMake a manual save before every big choice. A slip is easy to undo if you can load a save from just before it.
